# AQUADRON - Underwater Drone Water Quality Monitoring System

## 📋 Deskripsi Proyek
AQUADRON adalah sistem monitoring kualitas air berbasis drone bawah air yang dilengkapi sensor pH, TDS, dan Turbidity. Data ditampilkan secara real-time melalui dashboard web dengan database lokal IndexedDB.

## 🚀 Fitur
- ✅ Monitoring real-time pH, TDS, Turbidity
- ✅ Koneksi Bluetooth ke ESP32
- ✅ Database lokal IndexedDB (offline support)
- ✅ Visualisasi data dengan Chart.js
- ✅ Export data ke CSV/JSON
- ✅ Sistem alert dan notifikasi
- ✅ Statistik dan analisis data
- ✅ Responsive design
